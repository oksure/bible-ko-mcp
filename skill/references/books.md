# Bible Books & Translations

Book references accept the **English name**, the **Korean name (한글)**, or the **3-letter code** — all three resolve to the same book.

## Translations

| Code | Name |
|------|------|
| `GAE` | 개역개정 (Revised Korean) |
| `GAE1` | 개역한글 (Korean Revised Version) |
| `NIR` | 새번역성경 (New Korean Revised Version) |
| `KOR` | 공동번역 (Common Translation) |
| `CEV` | CEV (Contemporary English Version) |

> `GAE` (개역개정) is the reliable default. GAE1/NIR/KOR may return 0 verses on the source site; verify with GAE.
